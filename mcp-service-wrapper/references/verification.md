# 实施验证清单

根据本次接入范围选择测试，不以大量 mock 测试替代真实安全边界。对每项记录：输入身份/资源、实际结果、业务 Service 是否执行、持久化是否变化。

## 必测调用边界

| 场景 | 期望行为 |
|---|---|
| 无凭据、无效/过期/撤销 token、错误 audience | HTTP 401；可发现 challenge；业务零调用 |
| 有效 token 缺少所需 scope | HTTP 403 insufficient_scope；不能只断言“已有认证” |
| 有效 scope 但没有动作或对象权限 | 拒绝工具执行，业务零副作用 |
| 用户 A 猜测 B 的对象 ID、跨租户、混合权限批量 ID | 服务端拒绝不可授权对象；不能依赖先调用列表 |
| 列表/详情正常访问 | 可见数据与既有业务渠道权限一致 |
| 工具参数伪造 user/role/token/tenant | 不改变可信身份与权限 |
| MCP token、Web cookie、开放 API token 互换入口 | 不发生未设计的认证回退 |
| 工具内部报错 | 客户端收到错误而非成功；无凭据或栈泄露 |

测试需穿过真实 HTTP 安全链和实际 `tools/call`，至少断言一次未授权请求没有调用 Service。直接调用 filter 或 mock Authentication 不能证明集成权限正确。

## 按所实现能力追加

- **OAuth：** PKCE 错误、client/resource/redirect 不匹配、授权码重复与并发消费；consent 拒绝及 CSRF；元数据里的每个声明与真实端点相符。
- **生命周期：** 真实数据库并发刷新仅一次成功；refresh 重放整族撤销在事务结束后仍有效；授权管理撤销后 access/refresh 均失效；用户禁用与权限降低按约定生效。
- **会话/异步：** 同用户刷新后正常使用；用户/client/tenant 变化不能复用 session；多用户并发隔离；线程池复用后无遗留身份；后续 POST/GET/DELETE 都不能只凭 session ID 授权。
- **预览确认：** 预览无副作用；改参数、换用户、过期、并发重复消费均不重复执行；权限/模板变化后拒绝旧预览；业务需要人工审批时验证没有真实批准记录无法执行。
- **写入幂等：** 请求超时重试、确认消费后业务失败的恢复路径可解释；不会盲目重试重复创建/导出/发消息。
- **transport：** 用目标 MCP 客户端完成初始化、tools/list、合法及非法 tools/call；验证 Origin、反向代理、SSE 长连接和取消。目录隐藏的工具直接调用仍被拒绝。

只报告实际执行的检查；未运行端到端、数据库并发或目标客户端验证时明确注明，不以格式校验或单测通过代替这些结果。
